# 麦麦不贪吃（Token Ledger）

把宿主记录下来的 token 用量，换算成**可以核对**的费用。

> *“麦...麦麦才没有吃那么多Token！”*

## 它做什么

- 读取宿主 `llm_usage`（`ModelUsage`）与 `chat_sessions`，**只读**，不写库、不发消息。
- 按**自维护价格库**重算每次请求的费用：支持常规价与峰谷价（工作日/时段/节假日规则）、缓存命中价、按次计价。
- 首页卡片给近 7 天摘要；工作区页面给总览、总花费趋势、按群与按模型明细。
- 价格库**按实际用过的模型生成**：只列出窗口内真正产生过调用的模型，未识别的不猜价，留给你手动补。
- 内置 DeepSeek 官方价目（含峰谷价）：扫描到用量模型时，只补缺失的常规价/峰谷价（标记 `auto_adapted`），不覆盖你手工改过的值，并在条目里记来源与抓取时间。
- 估算工具调用费（联网检索类工具按次数计价），可与平台账单对照。

## 安装

1. 在插件市场安装，或把本仓库放到 `plugins/` 下并重启宿主。
2. 首次加载后，插件会读取最近 30 天的用量，按实际用过的模型生成价格库条目。
3. 打开插件配置页补全价格（见下一节），保存后账本立即按新价格重算。

## 配置

配置分三节（`plugin` / `pricing` / `peak`），另外价格库条目在“价格库”页面里维护。

| 配置节 | 主要项 | 说明 |
| --- | --- | --- |
| plugin | `enabled`、`config_version` | 启用开关与配置版本 |
| pricing | `usage_window_days`、`exclude_test_tasks`、`usd_cny_rate`、`include_background`、`refresh_seconds`、`prices` | 统计窗口、排除 WebUI 模型测试调用、汇率、是否含后台调用、刷新间隔、价格条目（作为首次种子） |
| peak | `weekdays`、`windows`、`holiday_mode`、`extra_holidays` | 全局峰谷规则：默认周一至周五 09:00–12:00、14:00–18:00（北京时间）为高峰 |
| 价格库条目 | `peak_weekdays`、`peak_windows`、`peak_holiday_mode` | 单个模型的峰谷覆盖（留空=跟随全局）；不同厂商峰谷时段不同时用这一层 |

价格条目按「服务商 + 模型」匹配，字段包括：常规输入/缓存命中输入/输出价、高峰三价、计价单位（元/百万 token 或 元/次）、币种、官方来源、抓取时间、确认状态、别名。

## 使用方法

- **账本页**（工作区「账本」标签）：时间范围（24 小时 / 7 天 / 30 天）、总览卡片、总花费趋势折线图、按群的 Token 与费用柱状图、按群明细表。
- **价格库页**（工作区「价格库」标签）：
  - 一级列表只显示模型名、服务商、确认状态与当前价格摘要；
  - 展开后分两列：左侧常规报价（含来源与抓取时间），右侧峰谷报价；折叠行也会显示价格摘要与峰谷价；
  - 峰谷时段可按模型单独覆盖（留空=跟随全局，填 `-` 清除），用于不同厂商峰谷时段不一致的模型；
  - 底部可保存价格、只改确认状态；也可以手动「新增一条」价格（用于尚未产生调用或按次计费的模型）；
  - 工具调用价按「元 / 1000 次」单独维护；
  - 右上角「刷新」为单飞队列：正在刷新时再点会排队，刷新期间按钮置灰，宿主并发/限流会自动退避重试。
- **首页卡片**：近 7 天花费、Token 量、请求数、Top 群与未识别模型提示，点「查看详细统计」跳转宿主统计页。

## 工作原理

1. 按窗口读取 `llm_usage` 明细（缓存命中/未命中 token、输出 token、请求时间、会话 ID）。
2. 按 `(provider, model_assign_name/model_name)` 聚合，用别名归一与宿主展示名生成价格库行；命中内置官方价目的模型自动补齐缺失价格（只补空缺，不覆盖手工值）。
3. 每条请求按时间落入峰谷时段，用价格库单价重算费用；按与会话映射归到具体群聊。
4. 结果缓存到 `data/plugins/<插件 id>/` 下（报告缓存与首页卡片缓存），首页卡片在注册时读取缓存，确保打开即可见。
5. 页面请求命中缓存时立即返回旧值并在后台重算，不会卡住界面。

## 隐私与安全

- 只读数据库，不写业务表；不发送任何消息。
- 不读取宿主安装目录下的配置文件（如 `model_config.toml`）；价格与缓存只写在插件自己的数据目录。
- 请求与费用明细只在本机展示，不外传。

## 兼容性

- 宿主 MaiBot 1.3.x；插件 SDK 2.8.0 – 2.21.x。
- 无额外 Python 依赖；不需要联网即可运行（价格需你自己核对后填写）。

## 验证

- 官方 `ManifestValidator` 校验通过；配置 schema 与页面声明可正常加载。
- 仓库自带自检：价格重算、峰谷判定与按模型覆盖、按群明细、未识别模型识别、官方价目自动适配、缓存与后台刷新行为。

### 计算口径与误差说明

本插件的费用全部由**本地重算**得出，不是平台账单的复制。计算环境与条件如下：

- **数据来源**：只读取宿主数据库 `llm_usage` 中已记录的每次模型请求（时间、模型标识、输入/缓存命中/输出 token），以及 `chat_sessions` 用于归群；不抓取平台账单、不联网、不读取宿主配置文件。
- **计价依据**：使用「价格库」中你保存并确认的单价；内置官方价目只在字段缺失时补齐，过期后不会自动更新；峰谷判定按价格库的时段、星期与节假日规则（北京时间）执行。
- **可能产生误差的原因**：官方调价后价格库未更新；价格填错或漏配（未识别模型按 0 计会低估费用）；峰谷时段/节假日与厂商实际执行口径不一致；缓存命中统计口径差异；失败与重试请求的计费方式；联网检索等工具调用按次数估算；免费额度、赠送余额与汇率波动（美元定价模型）。
- **统计范围**：默认包含后台调用（无会话记录的任务），可切换为「仅聊天」；宿主未写入 `llm_usage` 的调用（例如部分语音链路）不会出现在账本中。
- **结论**：账本用于**趋势观察与内部分摊**，金额仅供参考，**不应作为对账或计费依据**；与平台账单不一致时以平台账单为准。

### 使用风险

- 价格数据需自行核对：内置官方价目与抓取时间会随官方调价而过期，插件不会自动联网更新；价格填错会直接导致费用估算偏差。
- 插件依赖 MaiBot 宿主能力与内部数据结构（`database.get`、`llm_usage` / `chat_sessions` 表结构），宿主升级后若接口变化可能需要适配。
